# Серый Брод — идеи вне плана

Записываются сюда и не делаются, пока не попросят.

## Бой
- Тяжёлая атака по удержанию кнопки (сейчас есть только лёгкая).
- Лук или метательные ножи для травницы.
- Отвары как боевые расходники (лечение, стойкость) с анимацией `Consume`.
- Отдельная анимация бега со щитом: сейчас при блоке в движении играет стоячая `Idle_Shield`.

## Враги
- Волки, которые воют и сбегают, когда стая теряет половину.
- Разбойник, который после подкупа возвращается с дружками, если Мара снова идёт той же тропой.
- Отдельная анимация «стойка с топором» для атамана.

## Торговля
- Доверие торговца растёт от сделок (сейчас меняется только событиями).
- Починка и заточка у кузнеца, износ оружия.
- Заказ редкой травы у Велены за награду.

## Открытый мир
- Бой верхом (удар с седла), падение с лошади от сильного удара.
- Анимация посадки и спешивания; седло и уздечка на модели.
- Плавание и лодка у мельницы.
- Погода: дождь, гроза, туман по утрам.
- Задания отшельника: травы, редкие растения в дальних местах, третья глава.
- Ещё места: заброшенный монастырь, пещера, деревня за рекой.
